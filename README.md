# 🌱 AGROBOT — AI-Powered Farming Assistant

> **Powered by NexAI**

AGROBOT is an AI-powered agricultural assistant designed to help farmers and agriculture enthusiasts with crop guidance, weather information, fertilizer recommendations, government schemes, and plant disease detection.

The application is built with **Python, Flask, AI APIs, SQLite, HTML, CSS, and JavaScript**.

---

## 🚀 Features

### 🤖 AI Farming Assistant
Ask agriculture-related questions and receive AI-powered responses.

Example questions:

- How do I grow rice?
- What fertilizer is suitable for wheat?
- How can I improve maize production?
- What are common crop diseases?

### 🌦️ Weather Information

Get current weather information for the configured location using the OpenWeather API.

The application can also provide basic farming advice based on weather conditions.

### 🌾 Crop Calendar

Currently supports crop information for:

- Rice
- Wheat
- Maize
